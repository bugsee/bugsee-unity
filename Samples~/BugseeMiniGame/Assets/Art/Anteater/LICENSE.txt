Anteater character assets
========================

Generated/
  ScarletSnout.fbx            — Meshy quadruped auto-rig + Walking clip (preferred)
  ScarletSnout_Normal.png     — normal map from Meshy (optional; runtime uses coral lit)
  AnteaterMesh.obj / .mtl     — earlier static remesh (~14k tris), fallback if FBX missing
  AnteaterMesh.source.glb     — remeshed intermediate from the first Meshy GLB export

Resources/Anteater/
  ScarletSnout.fbx            — runtime load of the rigged model
  ScarletSnoutAnim.controller — built by Assets/Editor/AnteaterFbxSetup.cs (Generic, Speed)

Source: Meshy AI image-to-3D from Bugsee anteater logo (“Scarlet Snout”), then Meshy
quadruped Auto-Rig + Walking animation. Export had Walk skin; no albedo (coral
material applied at runtime).

Animator: Generic, root motion off. Stick drives float `Speed` (0 = frozen rest,
>0 = Walk). CharacterController remains authoritative.

Fallback chain: rigged FBX → static OBJ → procedural AnteaterBuilder.

Respect Meshy Terms of Service for the generated geometry. Bugsee logo PNG in
this folder remains Bugsee artwork for the spawn totem.
